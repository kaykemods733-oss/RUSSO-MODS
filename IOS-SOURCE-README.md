# Projeto-fonte da IPA

`3105-1.1.1-original.tar.gz` é o projeto iOS usado como entrada pelo workflow de compilação.

`APIClient.h` e `APIClient+Config.m` são os arquivos auxiliares usados durante a integração do build.

O projeto é extraído pelo YAML para `source/3105-1.1.1/` antes das alterações e da compilação.
